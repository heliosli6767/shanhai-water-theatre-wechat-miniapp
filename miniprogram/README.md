# 山海水戏微信小程序

这是可直接导入微信开发者工具的原生小程序目录，不依赖 Web、iOS、Android 或旧素材仓库。

它包含九个故事分包、27 幕压缩场景、透明人物与道具、五个水幕舞台，以及微信 VisionKit 手势识别管线。

## 导入

在微信开发者工具中选择“导入项目”，目录选仓库根目录或本文件夹 `miniprogram/`，点击编译。已内置首页及九个故事的完整数据，默认无需另外启动 backend 或配置 API。VisionKit 摄像头和 21 点手部骨架必须在支持的真机上验收。

可选在线 API 模式在 `services/config.js` 中设置 `dataSource = 'api'`，随后配置地址：

- 开发者工具模拟器默认连接 `http://127.0.0.1:4174`。
- 手机调试应改为电脑局域网地址，或已经部署的 HTTPS 地址。
- 体验版和正式版必须填写 HTTPS 地址，并在微信公众平台配置合法请求域名。

仓库不包含 AppSecret、Token 或其他服务端密钥。
